## Como abrir e executar no Visual Studio Code

Você não precisa instalar nenhuma biblioteca, framework ou servidor complexo. Escolha uma das duas formas abaixo:

### Opção 1 — Usando a extensão Live Server (recomendado)
1. Abra o **Visual Studio Code**.
2. Clique em **File > Open Folder...** (ou **Arquivo > Abrir Pasta...**) e selecione a pasta `mente-em-equilibrio`.
3. Caso ainda não tenha, instale a extensão **Live Server** (de *Ritwick Dey*) na aba de Extensões do VS Code.
4. Abra o arquivo `index.html`.
5. Clique em **Go Live** no canto inferior direito do VS Code (ou clique com o botão direito em `index.html` e selecione **Open with Live Server**).
6. O site será aberto automaticamente no navegador.

### Opção 2 — Abrindo diretamente no navegador
1. Acesse a pasta `mente-em-equilibrio` no gerenciador de arquivos do seu computador.
2. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no navegador padrão.

## Funcionalidades incluídas

- Menu de navegação fixo com rolagem suave entre seções e destaque automático da seção atual.
- Menu adaptado para celulares e tablets (botão hambúrguer com abertura/fechamento acessível).
- Cards responsivos com efeito de brilho discreto ao passar o mouse.
- Animações suaves de entrada ao rolar a página.
- Seção interativa **Mitos e Verdades** com perguntas clicáveis.
- Botão flutuante para voltar ao topo.
- Links para fontes confiáveis de saúde pública.
